ManifestMe Accessibility

Last updated: August 4, 2026

This page describes what ManifestMe currently supports for accessibility, and — just as importantly — what it does not yet support. We would rather tell you plainly than have you download the app and find out.

What ManifestMe supports today

FeatureStatus
Sufficient contrast Supported. Every text colour in the app is checked against every background it appears on, and each combination meets or exceeds the WCAG 2.1 AA ratio of 4.5:1. This is enforced by an automated test that fails the build if a colour change drops below it.
Reduced Motion Supported. Turning on Reduce Motion in iOS Settings disables the app's animated transitions and the looping "breathing" glow effects.
Dark interface Supported. ManifestMe uses a dark interface throughout.

What is not supported yet

FeatureStatus
Larger Text (Dynamic Type) Not supported yet. Text does grow when you increase the system text size, but at the largest accessibility sizes some labels on the Home screen wrap or get clipped. We are fixing the layouts and will update this page when it is reliable end to end.
VoiceOver Partial, and therefore not claimed. Key items are labelled — including each generated vision-board image, which is described using the prompt that produced it — but we have not yet verified that every control in every screen is reachable and correctly labelled.
Voice Control Not supported yet. It depends on the same complete labelling work as VoiceOver.

Captions and audio descriptions

Not applicable. ManifestMe contains no pre-recorded video or audio. The optional "Read Aloud" feature uses the system speech synthesiser to read affirmations that are already displayed on screen as text, so there is no audio-only content to caption.

Tell us what is broken

If something in ManifestMe does not work with the assistive technology you use, please email support@fritzthatcat.com and describe what you were trying to do. Accessibility reports are treated as bugs, not feature requests.
